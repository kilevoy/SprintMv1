## Правила использования

- Каталог является версионированным источником цен, а не инженерным справочником допустимых сечений.
- Резолвер принимает только точное совпадение canonical mark, явного alias или кода 1С.
- Профиль без массы можно оценивать по цене, но нельзя использовать для расчёта массы без отдельного доказанного источника.
- Дубликаты кодов и конфликтующие цены возвращаются typed diagnostics; в текущем импорте таких групп не обнаружено.
- Старые позиции профнастила/доборов остаются в legacy dataset до отдельного подтверждения их строк в новом 1С-файле.
