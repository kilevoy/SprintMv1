# Engineering Preview: v1.5 стеновой контроллер

В Engineering Preview добавлены явные поля контроллера стеновой геометрии для
обеих ориентаций:

- `B12` — расчётная высота стены;
- `B13` — шаг опор;
- `e` — половина угловой зоны.

Для `SIDE` значение `B11` берётся из доказанного v1.5 mapping как длина
здания. Для `END` `B11` берётся как пролёт. Эти два соответствия не являются
новой инженерной формулой: они перенесены из аудита пар ориентаций v1.5.

Введённые значения сохраняются в `ProjectInput.enclosure.wall_geometry` с
provenance `MANUAL` и не выдаются за автоматическую реконструкцию Excel.

## Текущая граница расчёта

После нажатия «Рассчитать» приложение вызывает
`calculateProjectV15WallGirt` для `SIDE` и `END`. Если явная геометрия
отсутствует, возвращается `ENCLOSURE_PROJECT_GEOMETRY_REQUIRED`. Если
геометрия введена, но полный доказанный AUTO runtime (нагрузка, диапазоны
профилей, ограничения шага и материал) ещё не передан, возвращается
`ENCLOSURE_WALL_GIRT_RUNTIME_REQUIRED`.

Профиль, шаг, число рядов и масса показываются только при статусе `PROVEN`.
Климатическая нагрузка не подставляется в `w0_kPa` автоматически, а
отсутствующий runtime не заменяется нулём, ближайшим профилем или ручной
догадкой.
