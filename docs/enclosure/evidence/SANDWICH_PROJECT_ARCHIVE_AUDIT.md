# Архивный аудит утеплённых Sprint M с СП

Режим: read-only. Исходные XLSX не изменялись.

## Выборка

Проверены листы `12м` в восьми сохранённых книгах архива:

| Проект | Признак утеплённого исполнения | `12м!C12` | `12м!E15` |
|---|---|---|---:|
| 21517 | СП | СП | 150 мм |
| 21608 | СП | СП | 100 мм |
| 21631 | СП | СП | 100 мм |
| 21701 | СП | СП | 150 мм |
| 21875 | СП | СП | 100 мм |
| 21911 | СП | СП | 120 мм |
| 21912 | СП | СП | 120 мм |
| 22069 | СП | СП | 100 мм |

`12м!D15` во всех случаях имеет подпись `Утепление стен:`. Значение `E15`
отличается между проектами, поэтому толщина стеновой панели/утепления является
проектным параметром.

## Что происходит с ригелями

В книге 22069 структура блока видна непосредственно:

```text
12м!B33 = Стены
12м!B34 = ПС 245х65х1,5
12м!B35 = ПС 245х65х1,2 окр.
12м!B36 = ПС 145х1,5 окр.
12м!B37 = ПС 145х1,2 окр.
```

Количество:

```text
12м!C34 = blank
12м!C35 = 0
12м!C36 = 0
12м!C37 = 0
```

Масса этих строк считается как `F = C × E`, поэтому для профилей стенового
ригеля она равна нулю. Тот же результат наблюдается во всех восьми книгах
выборки: `C35:C37 = 0`, а `C34` пустая или нулевая.

Это подтверждает рабочее правило расчётчика для типового утеплённого Sprint M:
отдельный подбор стеновых ригелей `ПС...` в комплект СП не включается.

## Что всё-таки остаётся в блоке стен

В 22069 после строк `ПС...` присутствуют отдельные позиции:

```text
12м!B38 = У.115 внутр.2м МП
12м!B39 = У 115 наруж.2м. МП
```

Они имеют ненулевые количества и относятся к доборным/стыковочным элементам
оболочки, а не к основным несущим стеновым ригелям. Поэтому «ригели не
считаются» не означает «вся стеновая комплектация равна нулю».

## Доступные варианты комплектации

На листе `12м` в 22069 перечислены варианты оболочки:

```text
H7  оцинкованный профлист
H8  окрашенный профлист
H9  сайдинг (горизонт)
H10 фасадная панель (верт.)
H11 ГВЛ
H12 Проект-1
H13 Проект-2
```

Это список вариантов, а не доказательство активной ориентации панели. Активный
признак утеплённого исполнения в проверенных книгах — `C12 = СП`.

## Вывод для Core 2

Для типового сценария:

```text
envelope = SANDWICH_PANEL
mounting = HORIZONTAL (операционное правило расчётчика)
```

Core 2 должен:

- не запускать подбор структурных `ПС...` стеновых ригелей по умолчанию;
- рассчитывать панели, доборы, стыки, крепёж и их массу/стоимость;
- сохранять возможность отдельной ветки ригелей для вертикального монтажа,
  нестандартного шага рам, проёмов и специальных нагрузок;
- не превращать отсутствие `ПС...` в нулевую массу всей ограждайки.

## Ограничения доказательства

Архивные книги подтверждают повторяющийся результат комплектации, но не дают
отдельной формулы «95% горизонтальной раскладки». Процент остаётся
подтверждённым владельцем методики операционным правилом. Для универсального
инженерного решения ещё нужна первичная таблица допустимых пролётов
сэндвич-панелей и явное поле ориентации панели.
