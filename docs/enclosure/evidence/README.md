# Enclosure evidence intake

This directory is reserved for source-backed cold-enclosure evidence.

Every finding must record:

- category;
- source workbook/archive and stable identifier;
- source sheet/cell or formula where available;
- project/fixture id;
- evidence status;
- what is proven and what remains unknown;
- whether implementation is allowed.

Parallel-AI findings remain `UNKNOWN` until the provenance fields are filled.
Original XLSX/PDF archives do not belong in this directory or in Git.
