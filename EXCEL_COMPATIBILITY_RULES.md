# Правила совместимости с Excel

## Общий принцип

Compatibility mode повторяет формулу, порядок вычислений, типы и ошибки исходной книги. Инженерское «исправление» выполняется только в отдельном режиме и после утверждения.

## Функции и выбор

| Конструкция | Требование parity |
|---|---|
| `ROUND` | повторять Excel midpoint/знак и число разрядов; не заменять форматированием |
| `ROUNDUP` | округлять от нуля с Excel-семантикой |
| `CEILING`, `CEILING.MATH` | различать legacy `CEILING` и `CEILING.MATH`, особенно для отрицательных значений |
| `FLOOR` | повторять знак significance и Excel error semantics |
| `MATCH(...,0)` | точное сравнение, первая найденная позиция, `#N/A` при отсутствии |
| approximate `MATCH` | требовать правильную сортировку и повторять последний допустимый индекс; не превращать в exact |
| `INDEX` | Excel 1-based indexing и propagation ошибок |
| `VLOOKUP` | сохранять exact/approx флаг, первый match и левый ключ |
| `SMALL` | учитывать дубликаты; sentinel `999999999` остаётся числом-кандидатом |
| `MIN/MAX` | повторять игнорирование/учёт типов согласно контексту диапазона/аргумента |
| `IF` | вычислять выбранную ветку; сохранять Excel coercion условия |
| `IFERROR` | ловить все Excel errors, но не обычные строки-сентинелы |

## Типы и ошибки

- `#N/A`: штатное исключение кандидата только там, где downstream явно его обрабатывает; в выбранном результате — typed error.
- `#REF!`: не восстанавливать предполагаемый адрес. В ветке шаг 500 мм прогонов повторять ошибку.
- `#VALUE!`, `#DIV/0!`: сохранять как отдельные typed errors, не `null` и не ноль.
- Строка `"0"`, число `0`, `"-"`, пустая строка `""` и действительно пустая ячейка — пять разных состояний.
- Пустая ячейка в числовом сравнении/арифметике приводится только так, как это делает Excel для конкретного оператора; не применять глобальный `blank=0`.
- Сравнение текста учитывать безрегистровую Excel-семантику и точные пробелы/символы в ключах.

## Порядок выбора

- `MATCH`, `VLOOKUP`, связки `SMALL/MATCH/INDEX` сохраняют first-match behavior.
- При равных массах/коэффициентах сохраняется порядок таблицы и исходное условие `>` против `>=` (`tie-breaking`).
- Не сортировать справочники автоматически.
- Не округлять промежуточные значения (`intermediate rounding`), если в формуле нет `ROUND*`; формат ячейки не меняет stored value.
- Единицы конвертировать в тех же местах цепочки. В частности, `D69` остаётся кг/м², `E68` — т, `V28` — кг, `T28` — кг/м².

## Умножение на ноль

Выражение `component * 0` нельзя объявлять мёртвым: сам `component` может дать ошибку, строковое coercion или участвовать в аудите. Для каждого такого компонента модель хранит:

```text
calculated_value
inclusion_factor
effective_value
```

и классифицирует его как отключённый только после доказательства downstream. В текущем сканировании основной книги буквальные формулы `*0` не обнаружены; правило обязательно для переноса будущих/связанных формул и не разрешает удалять условно нулевые ветки.

## External/cache compatibility

- External-link cache — свидетельство сохранённого результата, но не источник формулы или актуальности.
- Встроенные таблицы извлекаются как versioned static data с адресом, типом, raw value и checksum исходного XLSX.
- Compatibility fixtures должны включать обычный сценарий, ветку 24 м, недоступный профиль, шаг прогона 500 мм, город вне `СП РК EN`, город внутри `СП РК EN`, пустой/ручной шаг рам и ненулевые проёмы.
