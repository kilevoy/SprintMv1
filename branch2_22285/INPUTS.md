# INPUTS

## Поля верхней формы

| Ячейки | Смысл по подписи | Наблюдаемые значения |
|---|---|---|
| `C5`, `D5` | `Снег/Ветер` | на всех листах `3`, `2`; обнаруженных локальных потребителей нет |
| `G5` | номер ТЗ | `22285`, `10107`, `11388`, `10108`, `10256` |
| `B6` | место строительства | `Коркино` на `12м`, `Челябинск` на остальных |
| `B7` | объект | `Ангар` или `АТ` |
| `C8` | пролёт, м | 18 / 15 / 18 / 21 / 12 |
| `C9` | длина, м | 48 или 60 |
| `C10` | высота, м | 6 на всех листах |
| `C11` | шаг рам, м | 4 или 6 |
| `I3` | наружная обшивка, код | 2 на всех листах |
| `I4` | внутренняя обшивка, код | 0 на `12м`, `15`, `18`; 2 на `21`, `1ск` |
| `C12`, `C13` | расшифровка обшивок | формулы `IF` на четырёх листах; вручную `СП`/`нет` на `12м` |
| `E14` | утепление кровли, мм | 150 или 200 |
| `E15` | утепление стен, мм | 100 или 150 |
| `E17` | перегородки, м² | 0 на всех листах |
| `G8` | уровень ответственности | 2 или 3 |
| `G9` | степень огнестойкости | 5 |
| `I13` | выбор `Альбом-1` / `Проект-2` | 1 на всех листах |

## Формульные производные верхней формы

- `I17 = CEILING(C9/C11+1,1)` — расчётное число рам/шаговых позиций; текущие кэши: 13, 11, 11, 16, 11.
- `J16` — число рам по геометрической ветке. На `12м`, `15`, `18`, `21`: `C8/2/COS(15°)*2`; на `1ск`: `C8/COS(10°)`. Это не округление до целого: кэши равны примерно 18.634, 15.529, 18.634, 21.740 и 12.185.
- `J14` — угол в радианах через `15*3.14/180` на четырёх листах и `10*3.14/180` на `1ск`.
- `J15 = COS(J14)`; у `1ск` дополнительно `K14 = SIN(J14`, `K15 = K14*J16`.

## Важная классификация

`C5` и `D5` выглядят как климатические входы, но поиск ссылок по формулам каждого листа дал 0 локальных потребителей для обоих полей. `B6` и подписи города также не участвуют в локальных формулах. Это не доказывает, что поля никогда не использовались в прежней версии или через внешний кэш, но в представленном XML прямого расчётного влияния не видно.

`I3`, `I4`, `I13`, `E17`, `C8:C11`, `E14:E15`, `G9` имеют доказанных потребителей. Их изменение способно менять количества материалов, ветви обшивки, перегородки, вспомогательные рамники и коммерческие итоги.

## Не найденные механизмы ввода

Нет data validation, поэтому список кодов в `H3:J13` — визуальный справочник, а не формально ограниченный Excel-ввод. Нет custom named ranges для входов. Пользователь мог вводить значения вручную поверх шаблона.
