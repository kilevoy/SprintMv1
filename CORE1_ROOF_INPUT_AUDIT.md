## 2. Executive finding

D20 — не просто подпись покрытия. Это ключ покрытия, который одновременно:

1. выбирает собственный вес покрытия через Подбор прогонов 2!B7;
2. входит в расчёт снеговой/постоянной нагрузки в Расчеты 2 и Расчеты МП390 2;
3. включает специальную ветку утеплённых систем через B18;
4. косвенно влияет на подбор профиля, шага и массы прогонов.

D21 — не дополнительный слой с отдельной массой. По формулам это ключ марки/профиля настила, который выбирает ветку таблицы допустимого шага прогонов. Его влияние проходит через:

D21 → Q5 → X11:X63 → D23 → Подбор прогонов 2!B14 → Расчеты*!B13:B16 → P28:V28.

Следовательно, классификация D21 — вариант C: технический legacy-параметр, ограничивающий допустимый шаг прогона. Вариант D (inactive) опровергнут: для С44-1000-0,5 и С44-1000-0,7 меняется D23, а при меньшем ограничении меняются профиль, шаг, масса и D69.

Физическая характеристика настила присутствует в названии поля и справочнике, но в проверенной книге нет формулы, которая добавляет массу настила из D21 отдельно от массы покрытия D20. Поэтому в Core 1 D21 следует трактовать как характеристику настила, используемую для проверки шага, а не как отдельную позицию BOM.

## 3. Доказанная карта зависимостей

### 3.1. Ветка покрытия D20

    вывод!D20
      ├─→ подбор!V5
      ├─→ Подбор прогонов!B6
      │     └─→ B7 = INDEX(P44:P63, MATCH(B6, N44:N63, 0))
      └─→ Подбор прогонов 2!B6
            ├─→ B7 — собственный вес покрытия, кг/м²
            ├─→ B18 — толщина утеплённой системы для "наше ..."
            └─→ D21:D24 — выбор конструктивной ветки прогона

    Подбор прогонов 2!B7
      └─→ Расчеты 2 / Расчеты МП390 2
            └─→ q, проверка профилей, выбор шага и массы

    P28:V28
      └─→ вывод!D35:E35, E8/E9
            └─→ вывод!D69

Для текущего D20 = С-П 200 значение Подбор прогонов 2!B7 равно 38,64 кг/м². В справочнике Подбор прогонов 2!N44:P63:

| Покрытие | Собственный вес, кг/м² | Формула/источник |
|---|---:|---|
| С-П 150 | 32,028 | 26,69 × 1,2 |
| С-П 200 | 38,64 | 32,2 × 1,2 |
| С-П 250 | 45,228 | 37,69 × 1,2 |

Это доказывает влияние D20 на roof self-weight. В Расчеты 2 и Расчеты МП390 2 B7 входит в выражения расчётного q; поэтому D20 может изменить не только строку массы покрытия, но и профиль/шаг прогона.

### 3.2. Ветка настила D21

На листе вывод:

    O5 = IF(OR(D20=...), "наше"/"профлист" → O7, 0)
    Q5 = IF(D21=0, IF(O5=0, D20, O5), D21)
    X11:X63 = INDEX(AP:AZ, MATCH(Q5, AP10:AZ10, 0))
    D23 = INDEX(W11:W63, MATCH(E23, X11:X63, -1))

В текущем сценарии:

- D20 = С-П 200;
- D21 = С44-1000-0,7;
- O5 = 0;
- Q5 = С44-1000-0,7;
- E23 = Подбор прогонов 2!B13 × 1,15 = 2,7959819575;
- D23 = 2150 мм.

D21 используется локально через Q5; прямых внешних ссылок вида вывод!D21 нет. Поэтому простого поиска внешних ссылок недостаточно: зависимость является внутрилитовой и далее выходит через D23.

### 3.3. Ветка итоговой МЕ

    вывод!D69 = IF(D9=0, E8, E9) + D68
    E8 = подбор!Z14 + Подбор прогонов!T28
    E9 = подбор!Z15 + Подбор прогонов 2!T28

В текущем cached state D9 пустая, D68 = 0, поэтому Excel выбирает ветку E8. При этом обе книги прогонов используют тот же D23 через свою ячейку B14, поэтому изменение D21 затрагивает и выбранную, и параллельную ветку прогонов. Для текущей книги:

- Подбор прогонов 2!T28 = 7,539 кг/м²;
- Подбор прогонов 2!V28 = 1550,88 кг;
- вывод!D69 = 30,2596736111.

Структурная часть подбор!Z14 в текущем сценарии равна 22,7206736111 кг/м² как разность D69 - T28. Прямой зависимости этой части от D21 не обнаружено; доказанная D21-чувствительная часть — T28/V28 и ограничение шага.

## 4. Роль диапазона Подбор прогонов 2!N44:P63

Диапазон является справочником покрытия и его собственного веса, а не справочником D21.

| Ключ | P, кг/м² |
|---|---:|
| С-П 150 | 32,028 |
| С-П 200 | 38,64 |
| С-П 250 | 45,228 |

Ветка D20 = С-П 200 не входит в перечисление N44:N53 для утеплённых систем. Поэтому D23:D24 переходят к профилям из Расчеты 2!E28:E29, а не к специальной ветке D26:D27 для утеплённых решений.

## 5. Контрольное сравнение D20 = С-П 200 при разных D21

### 5.1. Сценарии, закрытые cached values и формульным replay

| D21 | Q5 | D23 / B14, мм | purlin_profile | purlin_steel | purlin_step_mm | purlin_kg_per_m2 | purlin_weight_kg | D69 | Статус |
|---|---|---:|---|---|---:|---:|---:|---:|---|
| С44-1000-0,7 | С44-1000-0,7 | 2150 | 2ПС 200х65х2 | М.п.390 | 2140 | 7,539 | 1550,88 | 30,2596736111 | текущий cached baseline |
| С44-1000-0,5 | С44-1000-0,5 | 1150 | 2ПС 150х65х1,5 | М.п.390 | 1000 | 8,53825 | 1756,44 | 31,2589236111 | формульный replay |

Для второго сценария применена сохранённая расчётная сетка Расчеты МП390 2 при ограничении B14 = 1150:

- минимум в ветке B15:SH15 получается на шаге 1000 мм;
- D28 соответствует массе профиля 6,97 кг/м;
- по справочнику SK:SM это 2ПС 150х65х1,5;
- V28 = 585,48 × 18 / 6 = 1756,44 кг;
- T28 = V28 / (12 × 18) × 1,05 = 8,53825 кг/м²;
- D69 = 22,7206736111 + 8,53825 = 31,2589236111.

Изменение не является эффектом добавленной массы D21: собственный вес покрытия D20 остаётся 38,64 кг/м². Причина изменения — выбор другой колонки допустимых шагов и последующее ограничение B14.

### 5.2. Дополнительные допустимые марки

Для других известных марок D21 верхнее ограничение по той же таблице равно:

| D21 | D23 по MATCH(...,-1), мм | Что доказано без подмены cache |
|---|---:|---|
| Н60-845-0,7 | 2700 | ограничение шага будет выше текущего; точный новый профиль и масса требуют пересчёта ветки в Excel |
| Н60-845-0,8 | 3000 | ограничение шага будет выше текущего; точный новый профиль и масса требуют пересчёта ветки в Excel |

Для этих двух сценариев нельзя честно перенести текущие cached values в новые результаты: текущий cache рассчитан при B14 = 2150, а столбцы правее 2150 содержат значения, заблокированные условием текущего B14. Поэтому точные downstream outputs для них помечены REQUIRES RECALC, а не угаданы.

### 5.3. Нулевое/пустое D21

Для D20 = С-П 200 при D21 = 0 формула Q5 переходит на D20, то есть на ключ С-П 200. В таблице ограничений для этого ключа верхний предел равен 2550 мм. Это ещё раз показывает, что D21 не является неактивным полем: его нулевое состояние выбирает другую ветку ограничения, а не просто отключает параметр.

## 6. Ответ на вопрос о физическом смысле D21

Из формул можно доказать следующее:

- D21 назван Марка настила;
- его значение сопоставляется с заголовком одной из колонок AP:AZ;
- выбранная колонка содержит зависимость допустимой величины от шага W;
- результат используется для выбора D23, затем для ограничения допустимых шагов прогонов;
- отдельного + масса настила(D21) в цепочке массы покрытия не обнаружено.

Итоговая классификация: C — технический legacy-параметр для проверки шага прогона, с физическим содержанием марки профилированного настила. В будущей модели его можно хранить как roof_deck_grade, но не включать автоматически в BOM как самостоятельный материал и не считать, что его масса уже входит в D20 без отдельного доказательства.

## 7. D20/D21 для разных систем кровли

| D20 | D21 required | Что делает D21 | Влияние D20 | Роль в расчёте |
|---|---|---|---|---|
| С-П 50/80/100/120/150/200/250 | нет, есть fallback на D20 | если задан, переопределяет Q5 и выбирает колонку ограничения шага | собственный вес из N44:P63, q и подбор прогонов | выбор допустимого шага через Q5 |
| профлист | нет, при нуле fallback через O5 на O7 | заданная марка переопределяет default O7 | собственный вес 10,5 кг/м² из справочника | ограничение шага; отдельная масса D21 не доказана |
| наше 100/150/200/250 мм | нет, при нуле fallback через O5 на O7 | заданная марка переопределяет default O7 | собственный вес и B18/ветка утепления | ограничение шага плюс ветка утеплённой системы |
| наше ... с 1/2 слоями ГВЛ | нет, при нуле fallback через O5 на O7 | то же | D20 определяет толщину/ветку и вес | D21 не является отдельной массой в найденных формулах |
| малоуклонная кровля ... | не доказано как обязательное | при заданном значении участвует через Q5; при нуле fallback на D20 | собственный вес по ключу покрытия | требуется отдельная проверка корректности колонок для этой ветки |

Практический вывод: в legacy Excel D21 фактически optional с fallback, но его значение может быть расчётно значимым. Для нового интерфейса это означает: поле нельзя считать неиспользуемым только потому, что для него нет прямых внешних ссылок.

## 8. Реализация и проверка PURLIN_DECK_GAP

Ранее выявленный разрыв закрыт в `src/core1/purlin/PurlinCalculator.ts`:

1. exact D21 header lookup выбирает колонку `AP:AZ` из `deck_properties.csv`; разбора имени профиля нет;
2. лимит D23 вычисляется через сохранённую ось `вывод!W11:W63` и Excel-порядок `MATCH(E23,X11:X63,-1)`;
3. `B14` отражается в trace как cached/configured значение, но не используется как независимый глобальный cap: активная семантика — `effective_max = manual_D24_if_nonzero ?? deck_D23`;
4. `D25/B15` сохраняется как minimum-step branch, а `D24=0` — как отсутствие manual override;
5. кандидатная ветка воспроизводит формулы `SO`, `BFE`, `MIN/MATCH`, количество линий и массу; для MP390 используется локально зафиксированный `Расчеты МП390 2!SL16:SL29`;
6. Scenario A сохраняет `2ПС 200х65х2`, 2140 мм, 1550,88 кг и 30,2596736111 кг/м²; Scenario B получает `2ПС 150х65х1,5`, 1000 мм, 1756,44 кг и 31,2589236111 кг/м²;
7. шаг 500 мм по-прежнему отдаёт typed legacy `#REF!`, а неизвестная марка — typed `#N/A`.

Статус разрыва: `PURLIN_DECK_GAP = CLOSED`. Для Н60-845-* downstream parity с новым Excel cache всё ещё не заявляется: runtime даёт детерминированный результат внутри локальной модели, но без отдельного golden oracle это не `PARITY_PROVEN`.

## 9. Контракт UI/Core 1

Рекомендуемый смысл поля:

    field_name: roof_deck_grade
    business_name: Марка профилированного кровельного настила
    legacy_source: вывод!D21 → вывод!Q5 → вывод!X11:X63 → вывод!D23
    unit: марка/тип, без числовой единицы
    type: enumerated string
    required: conditional / optional with legacy fallback
    core1_source: user input, then default logic equivalent to Q5/O5
    core2_consumers: none proven in this audit
    current_status: LEGACY-CALCULATION-RELEVANT; PURLIN_DECK_GAP CLOSED

Не следует называть поле только Профнастил или Настил: такое имя скрывает, что значение используется как ключ ограничения шага и может изменить подбор прогонов. Также не следует автоматически объявлять D21 отдельной BOM-позицией.

## 10. Ошибки и неизвестности, оставленные без исправления

- Неизвестно, должны ли марки Н60-845-* разрешать шаги до 2700/3000 мм во всех листах 9–24 м или только в текущей таблице вывод; runtime теперь вычисляет их локально, но это требует отдельного Excel golden oracle для подтверждения parity.
- Для высоких лимитов 2700/3000 точные значения runtime определяются формульным replay, но не объявляются доказанными cached outputs без предоставленного пересчитанного Excel.
- Формулы с неизвестным или несовпавшим Q5 используют MATCH без защищённого fallback и могут дать #N/A; это не исправлялось.
- Нужно отдельно проверить, какой из E8/E9 является авторитетным результатом для всех режимов, хотя при текущем пустом D9 используется E8.

## 11. Итоговый ответ на восемь контрольных вопросов

1. Что такое D20? Ключ покрытия; он определяет собственный вес и ветку расчёта прогонов.
2. Влияет ли D20 на roof self-weight? Да: B7 = INDEX(P44:P63, MATCH(B6,N44:N63,0)).
3. Влияет ли D20 на подбор профиля/шага? Да, через q в Расчеты 2/Расчеты МП390 2 и через ветвление D21:D24.
4. Что такое D21? Марка профилированного настила, используемая как ключ таблицы допустимого шага.
5. Является ли D21 отдельной массой? По найденным формулам нет доказательства отдельного сложения массы D21.
6. Меняет ли D21 purlin outputs и D69? Да. При С-П 200 и замене С44-1000-0,7 на С44-1000-0,5 меняются D23, профиль, шаг, масса и D69.
7. Какой UI-контракт выбрать? Вариант C: технический параметр настила, влияющий на allowable purlin step. С fallback, эквивалентным Q5/O5.
8. Что нужно исправить в коде? Цепочка D21 → D23 → ограничение выбора прогонов закрыта; остаётся только получить golden Excel для parity высоких лимитов и дополнительных веток.
